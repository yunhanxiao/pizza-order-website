# Pizza Order Website

Semester Project for Web Computing

## Description

This project is a simple pizza ordering website developed with HTML, CSS, and Python CGI.

Users can:

- Enter their name
- Select a pizza type
- Choose a pizza size
- Enter the quantity

The form data is sent to a Python CGI script, which generates a dynamic order confirmation page.

## Input Parameters

- name (customer name)
- pizza (pizza type)
- size (pizza size)
- quantity (number of pizzas)

## Technologies

- HTML5
- CSS3
- Python 3.12
- CGI
